# yeonsup
# 추리게임 데이터 저장 실험실

Streamlit을 활용하여 세 가지 데이터 저장 방식의
정보 유지 및 복원 가능성을 비교하는 실험 프로젝트입니다.

## 비교 대상
1. Session State
2. JSON 파일
3. SQLite 데이터베이스

## 주요 기능
- 게임 진행 장소 변경
- 단서 수집
- 추리 노트 작성
- 게임 상태 저장
- 저장된 게임 상태 불러오기
- 현재 데이터 구조 확인

## 실험 방법

1. 저장 방식을 선택한다.
2. 장소 이동과 단서 수집을 진행한다.
3. 추리 노트를 작성한다.
4. 현재 진행 상태를 저장한다.
5. 브라우저를 새로고침한다.
6. 저장 상태를 불러온다.
7. 복원 여부를 비교한다.

## 추가 실험

requirements.txt 파일의 유무에 따라
Streamlit 앱의 실행 여부를 확인한다.

## 주의사항

JSON과 SQLite는 서버 내부에 데이터를 저장합니다.
Streamlit Community Cloud에서는 서버 재시작이나
교체 후에도 데이터가 유지된다고 보장할 수 없습니다.

실험 슬롯 ID는 사용자 인증 수단이 아니므로
개인정보를 입력하지 마세요.
